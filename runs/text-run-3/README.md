# Booking service

HTTP-сервис бронирования переговорных комнат. Использует PostgreSQL; при старте автоматически создаёт таблицу и индекс.

## Запуск

```sh
docker compose up --build
```

Сервис слушает порт `8080`. Для запуска вне Docker задайте `DATABASE_URL` либо параметры `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`; порт можно изменить через `APP_PORT`.

## API

- `POST /bookings` — создать бронь. JSON: `room_id`, `user_id`, `start_time`, `end_time`; время передаётся в RFC3339. Ответ `201` содержит созданную бронь, `400` — некорректные данные, `409` — пересечение с другой активной бронью этой комнаты.
- `GET /bookings` — список активных броней. `?room_id=...` фильтрует список по комнате.
- `PATCH /bookings/{id}` — перенести активную бронь. JSON: `start_time`, `end_time` в RFC3339; ответ `200` содержит обновлённую бронь, `400` — некорректные данные, `404` — активная бронь не найдена, `409` — пересечение с другой активной бронью этой комнаты.
- `DELETE /bookings/{id}` — отменить бронь; ответ `204`, либо `404`, если активная бронь не найдена.

Соседние интервалы допустимы: бронь, заканчивающаяся ровно в момент начала следующей, не считается конфликтом.
