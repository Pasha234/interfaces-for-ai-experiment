# Сервис бронирования переговорных комнат на Go

В эксперименте AI-агент реализует и расширяет сервис по текстовым требованиям или по готовым программным контрактам. Цель — оценить влияние контрактов на качество, сопровождаемость и расширяемость кода. Для оценки используются функциональные и регрессионные тесты, статический анализ и проверка соблюдения принципов SOLID.

Доклад «Программные интерфейсы как язык взаимодействия с искусственным интеллектом» подготовлен для университетской конференции «Актуальные проблемы информатизации в цифровой экономике и научных исследованиях — 2026».

## Как выполнить прогон

1. Скопируйте `templates/template-text` или `templates/template-contract` в `runs/<имя-прогона>`. В каталоге прогона создайте начальный коммит.

   ```bash
   git init
   git add .
   git commit -m "initial commit"
   ```

2. Откройте каталог прогона в IDE или в контексте агента и запустите генерацию с подходящим промптом `phase1_*.txt` из [prompts/](prompts/).
3. В каталоге прогона запустите сервис командой `docker compose up --build`. Из корня репозитория запустите тесты и статический анализ, подставив имя своего прогона.

   ```bash
   ./test.sh e2e-tests/phase1_test.go
   ./go-lint.sh text-run-4 phase1
   ```

4. Если тесты выявят ошибки, передайте их агенту и повторите проверку. Запишите результаты в CSV-файлы в [results/](results/).
5. Запустите генерацию с соответствующим промптом `phase2_*.txt` и повторите шаги 3–4. Дополнительно выполните `./test.sh e2e-tests/phase2_reschedule_test.go` и передайте `phase2` вместо `phase1` в `go-lint.sh`.
