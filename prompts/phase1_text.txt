Разработай HTTP-сервис бронирования переговорных комнат на языке Go с хранением данных в базе данных (порт `:8080`).

**Что должен уметь сервис:**

*   Создавать бронирование переговорной комнаты на заданный интервал времени. В одной комнате нельзя создать два пересекающихся по времени бронирования.
*   Показывать список активных бронирований (с возможностью фильтрации по комнате).
*   Отменять существующее бронирование.

**Внешний API (для интеграции с фронтендом):**

*   `POST /bookings` — тело `{"room_id", "user_id", "start_time", "end_time"}` (время в RFC3339). Возвращает `201` с объектом бронирования (добавляется `id`). При некорректных данных — `400`, при конфликте времени — `409`.
*   `GET /bookings` (опционально `?room_id=...`) — возвращает `200` и JSON-массив бронирований.
*   `DELETE /bookings/{id}` — отменяет бронь, возвращает `204` (или `404`, если бронь не найдена)
